# 霓虹禁语 · 赛博科技主题

以动画壁纸「嘘」为设计来源的深色赛博主题。近黑的夜色里，霓虹洋红的
环绕文字与瞳孔的电光青一起呼吸；面板是一整块醒着的玻璃终端，克制的
辉光、青色网格与洋红灯带让界面始终带着一层电子夜色的温度。

## 设计

- **背景**：动态壁纸 `assets/background.mp4`（2560×1440 / 30fps / 20 秒
  无缝循环，6MB）铺满窗口，静态帧 `assets/background.webp` 作为视频封面
  与加载失败时的回退；面板使用 18px 毛玻璃与 80% 的深色玻璃底，画面在
  窗口边缘与纸张四周透出；背景之上叠了一层几乎不可见的扫描线，模拟
  CRT 屏幕。
- **色板**：从画面取样——夜色 `#05050b`、深紫面板 `#0b0b14`、
  霓虹洋红 `#ff2ed1`、电光青 `#21e6ff`、离子紫 `#8b5bff`、
  雾紫正文 `#f2efff` 与 `#a49cc4`。
- **字体**：界面标题优先 Rajdhani（未安装时回落 PingFang SC / 微软雅黑），
  代码与键帽使用 JetBrains Mono / Fira Code 等宽字体栈；正文保留系统字体。
- **细节**：洋红渐变主按钮与灯管辉光、电光青次按钮、霓虹滑杆与
  洋红 → 紫 → 青的滚动条灯带、青色网格编辑器画布、洋红侧条标题、
  青色行内代码、洋红引用条与提示块描边。
- **学习模式**：信息密集的卡片纸面提高到 90%，保证计划与统计文字清晰；
  强调色跟随主题洋红，也可以在「自定义外观」里单独覆盖。
- **动效**：卡片悬停上浮 1px、边框亮起洋红灯管，180ms 缓动，尊重
  `prefers-reduced-motion`。

## 安装

在 Kiwi「设置 → 主题 → 导入主题」选择 `dist/neon-hush-1.1.0.zip`，
导入后启用即可。主题支持在「自定义外观」里覆盖背景、透明度与强调色。

### 动态壁纸

视频已包含在主题包内，导入后自动静音循环播放，无需额外上传。想换回
自己的背景，可在「设置 → 主题 → 自定义外观」上传图片或视频（≤ 100MB），
用户覆盖优先于主题包自带视频；清除自定义背景后会恢复动态壁纸。
每套主题的自定义外观独立保存，切走再切回来仍会恢复。

## 素材与许可

- 背景插画：用户提供的「哲风壁纸 · 嘘-文字环绕」动态壁纸。主题包内的
  `assets/background.mp4` 是压缩后的 1440p / 30fps 版本，
  `assets/background.webp` 是从原片截取的 2560×1440 封面帧。
- 字体：主题不内嵌字体文件，只声明系统字体栈，无额外授权要求。
