# 例会 · 像素卡通主题

以会议室像素插画为背景的浅色主题。奶油网格纸、炭墨描边、珊瑚橙强调色，
配合硬边投影与「按下去」的按钮，把整个工作区变成一张会开电脑的像素例会。

## 设计

- **背景**：会议室像素插画铺满窗口，保留画面里的奶油纸、鱼群与长桌；
  面板接近不透明，长时间阅读不干扰正文。
- **色板**：从画面取样——奶油纸 `#efe6d2`、炭墨 `#26282b`、珊瑚橙
  `#c0522c`、湖水蓝 `#4f8fc4`、橄榄绿 `#7c8a4c`、芥末黄 `#d9a441`。
- **字体**：标题与按钮使用 Fusion Pixel 12px Proportional 像素字体，
  正文保留系统无衬线字体，兼顾风格与可读性。
- **细节**：卡片与弹窗的硬投影、方块标题装饰条、斜纹橙红滚动条、
  键帽式 `kbd`、方块滑杆与像素网格纸张；设置页铺一整张奶油纸，
  长说明文字不会压在插画上。代码块只加描边，保留用户选择的语法配色。
- **动效**：卡片悬停与按钮按压采用两帧一格的 `steps()` 节奏，并尊重
  `prefers-reduced-motion`。

## 安装

在 Kiwi「设置 → 主题 → 导入主题」选择 `dist/pixel-huddle-1.0.2.zip`，
导入后启用即可。主题支持在「自定义外观」里覆盖背景、透明度与强调色。

## 素材与许可

- 背景插画：用户提供的「会议室-卡通插画」壁纸素材。
- 字体：[Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)
  （12px Proportional，简体中文子集），SIL Open Font License 1.1。
