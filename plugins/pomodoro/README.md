# 番茄钟组件插件

25 分钟专注 + 5 分钟休息的循环计时器。支持开始 / 暂停、跳过阶段、重置当前阶段，
并记录已完成轮数。专注 / 休息时长可在未运行时调整。

区块声明了 `pinnable: true`：可以置顶为跨页面的全局浮窗，切换路由或刷新页面后
继续计时，不需要把笔记一直开着。

## 安装

1. 在仓库根目录执行 `npm run package`，生成 `dist/pomodoro-1.1.0.zip`。
2. 打开 Kiwi「设置 → 插件与区块 → 导入插件」，选择 zip（同 key 覆盖安装会保留启用状态）。
3. 在编辑器输入 `/番茄钟`，或从「+ → 插件区块」插入。
4. 置顶入口：插件卡片 → 图钉菜单、预览弹窗「置顶」、编辑器区块工具条，或 `Ctrl / ⌘ + K`
   命令面板。也可以不创建笔记，直接置顶。

## 行为

- 运行状态通过 `endsAt` 时间戳保存；关闭笔记或刷新页面后继续计时。
- 仅在开始、暂停、跳过、重置和阶段结束时写入 props，避免每秒触发自动保存。
- 专注结束自动累计轮数并切到休息；休息结束切回专注，均需手动开始下一阶段。
- 阅读视图不显示操作按钮；仍运行中的计时器会继续走时。
- 置顶浮窗的状态保存在浮窗自己的 props（localStorage）中，不写回笔记；
  重复置顶只会聚焦已有窗口，不会重置正在运行的计时。
- 颜色使用 `--kiwi-*` 主题变量，跟随系统主题色与学习模式。

## 文件

- `plugin.json`：manifest（`version`、`pinnable` 等能力声明）
- `index.js`：入口 ESM，导出 `setup(host)`
- `style.css`：区块样式
