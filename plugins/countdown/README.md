# 倒计时组件插件

可调时长的倒计时卡片。支持开始 / 暂停、重置、预设时长（1 / 5 / 10 / 25 / 60 分钟）
与逐分钟微调，结束时会累计次数并弹出提醒。

区块声明了 `pinnable: true`：可以置顶为跨页面的全局浮窗，切换路由或刷新页面后
继续计时，不需要把笔记一直开着。

## 安装

1. 在仓库根目录执行 `npm run package`，生成 `dist/countdown-1.1.0.zip`。
2. 打开 Kiwi「设置 → 插件与区块 → 导入插件」，选择 zip（同 key 覆盖安装会保留启用状态）。
3. 在编辑器输入 `/倒计时`，或从「+ → 插件区块」插入。
4. 置顶入口：插件卡片 → 图钉菜单、预览弹窗「置顶」、编辑器区块工具条，或 `Ctrl / ⌘ + K`
   命令面板。也可以不创建笔记，直接置顶。

## 行为

- 运行状态通过 `endsAt` 时间戳保存；关闭笔记或刷新页面后继续计时。
- 仅在开始、暂停、重置、调整时长和结束时写入 props，避免每秒触发自动保存。
- 倒计时归零后自动停止、显示「已结束」并累计 `completedCount`；「再来一次」从完整时长重新开始。
- 运行中不可调整时长；时长范围 1 分钟 – 6 小时。
- 阅读视图不显示操作按钮；仍运行中的倒计时会继续走时。
- 置顶浮窗的状态保存在浮窗自己的 props（localStorage）中，不写回笔记；
  重复置顶只会聚焦已有窗口，不会重置正在运行的倒计时。
- 颜色使用 `--kiwi-*` 主题变量，跟随系统主题色。

## 文件

- `plugin.json`：manifest（`version`、`pinnable` 等能力声明）
- `index.js`：入口 ESM，导出 `setup(host)`
- `style.css`：区块样式
